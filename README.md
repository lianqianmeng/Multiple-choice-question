# ForChoiceExam (选择题测试 APP)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Android](https://img.shields.io/badge/Platform-Android%208.0%2B-green.svg)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Language-Kotlin%202.0-blue.svg)](https://kotlinlang.org/)

一款专为个人备考、刷题打造的 **Android 选择题/判断题测试应用**。支持直接导入 Excel (`.xlsx` / `.xls`) 题库，提供数据预览与自定义列映射，包含**顺序做题**、**随机抽题**与**错题本强化**三大测试模式。

---

## 💡 设计思路与架构

本应用基于现代 Android 推荐架构与响应式编程设计：

- **Jetpack Compose 现代化 UI**：全界面采用声明式 UI 开发，提供流畅的动画过渡、自定义答题卡矩阵及适应不同屏幕宽度的响应式布局。
- **本地优先（Offline-First）与 Room 数据库**：导入的题库、题目详情及答题/错题记录全部持久化保存在 App 本地 SQLite（Room 数据库）中，无需网络连接，保护隐私。
- **Apache POI 高能 Excel 解析引擎**：内置高效 Excel 解析模块，支持自动与手动配置列映射，智能提取单选、多选与判断题。
- **即时反馈与单向数据流（Unidirectional Data Flow）**：
  - 点击选项后即时校验，**正确选项绿框高亮**，**错误选项红框高亮**，并自动弹出标准答案与文字解析。
  - 多选题在底部导航栏提供【提交答案】按钮，勾选完毕点击后统一判分与查看解析。
  - 单选题/判断题无需切换页面即可直观看到对错与解析。

## ✨ 核心功能与使用方法

### 1. 题库导入与列映射预览
1. 在首页点击 **【选择文件】** 按钮，选择本地的 `.xlsx` 或 `.xls` 格式题库文件。
2. 弹出 **【导入预览与列映射】** 窗口：
   - **名称设置**：可自定义题库名称（默认使用文件名）。
   - **数据预览**：实时预览表格前 5 行真实数据，支持左右滑动查看所有列。
   - **列映射自定义**：自动识别标准 7 列模式或 9 列模式（`序号` | `题型` | `题干` | `选项A` | `选项B` | `选项C` | `选项D` | `参考答案` | `解析`），用户也可自由手动调整各字段分别对应第几列。
   - **表头过滤**：支持勾选/取消“忽略第 1 行（表头）”。
3. 点击 **【确认导入】**，系统将自动建立本地题库。

### 2. 刷题与测试模式
- **顺序做题模式**：
  - 按照 Excel 原始顺序逐题练习。
  - **进度记忆**：再次进入时弹窗提示：*“从第一题开始或从已顺序做题的下一题？”*，提供 **【从头开始】** 与 **【最新一题】** 两个快捷按钮。
- **随机抽题模式**：全题库题目随机打乱顺序进行抽查测试。
- **错题本模式**：自动搜集所有答错过的题目进行专项强化。做对或点击 **【标记已掌握】** 可将其移出错题本。

### 3. 快捷跳转与答题卡
- **按题型练习**：卡片上提供 **【单选题】**、**【多选题】**、**【判断题】** 快捷按钮，点击直达对应题型的第一题。
- **按题号精准跳转**：在输入框中输入目标题号（如 `100`），点击 **【开始做题】** 即可直达第 100 题。
- **浮动答题卡**：做题界面右上角提供 **【答题卡】**，可查看每道题的正确（绿）、错误（红）、未做（灰）状态，点击可直接跳转到任意题目。

## ⚠️ 使用限制与说明

1. **系统要求**：支持 Android 8.0 (API Level 26) 及以上版本的 Android 手机或平板。
2. **文件格式限制**：仅支持 `.xlsx` (Excel 2007+) 及 `.xls` (Excel 97-2003) 电子表格文件。
3. **选项数量**：当前版本主要针对标准选择题（最多支持 A、B、C、D 四个选项）及判断题设计。如果判断题只有两列选项或无选项文本，系统会自动补充为“正确”与“错误”。
4. **答案格式**：
   - 单选题：参考答案形如 `A`、`B`、`C` 或 `D`。
   - 多选题：参考答案形如 `AB`、`ACD` 或 `A,B,C`（系统会自动进行清洗与去重排序）。
   - 判断题：参考答案支持 `A` / `B`、`正确` / `错误`、`对` / `错`、`√` / `×`、`T` / `F` 等常用标记，系统会自动标准化为 `A`（正确）与 `B`（错误）。

## 🛠️ 构建与开发环境

- **IDE**：Android Studio Ladybug (2024.2.1) 或更高版本
- **Build System**：Gradle 8.x + Android Gradle Plugin 8.x / 9.x
- **Language**：Kotlin 2.0.21
- **Key Dependencies**：
  - `androidx.compose.material3:material3`
  - `androidx.room:room-runtime:2.8.5` (KSP)
  - `org.apache.poi:poi-ooxml:5.2.5`

```bash
# 运行单元测试
./gradlew app:testDebugUnitTest

# 编译 Debug APK
./gradlew app:assembleDebug
```
